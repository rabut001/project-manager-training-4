# 問題文と解説の作成

## 目的

17回、各25問について、問題文（`stem`、`choices`、`visuals`）と学習用の解説（`explanation`）を作り、`public/data/<id>.json` に入れる。

## 決めたこと

- 手順と観点は `docs/content-guide.md` に従う。進捗は `checklist/<id>.json` に置く。
- レビューは、作成時の会話を持たないサブエージェントに任せる。
- 最初に令和7年度秋期（`2025-r07-aki`）の1回分を試行する。問題文25行と解説100行がすべて `確認済み` になったら、利用者に中身を見てもらう。手順や観点に直す点があれば、`docs/content-guide.md` を直してから残りに進む。
- 残り16回は新しい回から順に進め、1回終わるごとにコミットする。

## 今回含めないもの

- 画面の変更。問題文は画面に出さない。

## 触るファイル

| パス | 内容 |
| --- | --- |
| `public/data/<id>.json` | `stem`、`choices`、`visuals`、`explanation` |
| `docs/changes/0002-am2-content/checklist/<id>.json` | 進捗 |
| `docs/content-guide.md` | 試行で手順を直すとき |

## 手順

1. `2025-r07-aki` のチェックリストを作る。
2. 問題文を起こし、サブエージェントのレビューで全行を `確認済み` にする。
3. 解説を書き、サブエージェントのレビューで全行を `確認済み` にする。
4. 利用者に試行の1回を見てもらい、必要なら `docs/content-guide.md` を直す。
5. 残り16回を、1回ずつ2〜3と同じ順で進める。
6. `uv run scripts/validate_data.py` が、全回の問題文と解説がそろった状態で通ることを確かめる。

## 確認

各回のチェックリストで、全行が `確認済み` になっていることを確かめる。
